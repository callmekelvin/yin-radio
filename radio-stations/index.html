Yin Radio Stations

This is a static data source for the Yin Radio application.

The station data is available at stations.json.

Data is fetched from Radio Browser and updated automatically via GitHub Actions.

A paginated version is also available in numbered folders (e.g. 0/stations.json, 1/stations.json) with 10,000 stations per page.

View the index.json manifest for a full list of pages and metadata.
